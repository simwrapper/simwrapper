# AGENTS.md

Guidance for AI agents working in the `python/` folder of the SimWrapper monorepo.

## Always use `uv`

Run all Python commands through `uv` (e.g. `uv run python ...`, `uv run pytest`,
`uv sync`). Do not invoke `python`, `pip`, or a bare virtualenv directly — the
project's dependencies are managed by `uv` and are not otherwise on PATH.

Note: `pyproject.toml` and `uv.lock` live in `python/`, so run `uv` commands from
there (or point `uv` at that project).

## Never scan `python/simwrapper/static/`

`python/simwrapper/static/` contains the built JavaScript app (minified bundles,
worker chunks, etc.), generated by `scripts/build-python.sh` from the root `dist/`
and gitignored. Do **not** read, grep, or search it — the files are
machine-generated, multi-megabyte, and not source. Exclude it from all
code searches and edits. The app's source is in the repo root `src/`.

## Versioning

The package version in `pyproject.toml` is bumped together with the app's
`package.json` by `pnpm release` at the repo root. Don't edit it by hand.
